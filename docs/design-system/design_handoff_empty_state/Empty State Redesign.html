Homepage · My Collection — Empty State

An empty box should sell the box.

The current first-run screen shows a beautiful gold frame holding nothing — it reads as broken, not as an invitation. Below: a quick diagnosis, then a redesign that turns the void into aspiration, with the readability tokens applied.

What's not working today
01 — Emotional read

It shows emptiness, not aspiration

Six blank cells in a luxury frame read as "loading" or "forgotten." Nothing makes you want to fill it.

02 — Hierarchy

Two headlines fighting

"Your Virtual Watch Box" (top-left) and "Your watchbox, on every device" (centered) compete — neither wins.

03 — Redundancy

"Add your first watch" — twice

Once as faint ghost text in a single slot, once as the button. The label is low-contrast and oddly placed.

04 — Readability

The old pale tones snuck back

Ghost text, subcopy and the "dream box" link all use the faint tan + gold the readability pass replaced.

Why this works
  • Same two-column grid as the populated box — tray left, panel right — so adding the first watch doesn't reflow the whole page.
  • The frame reads as potential, not void. Faded sample watches show the payoff; one bright dashed slot says exactly where to begin.
  • One headline, one primary action. The duplicate "add" prompt and competing centered title are gone; "Build a dream box" becomes a real secondary path.
  • Readability tokens throughout — ink headline, --color-muted captions at 6:1, antique gold for the accent link. No pale tan left.
